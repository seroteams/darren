Sero type system

Seven sizes. Fourteen named roles. Every piece of text in both apps picks one, and nothing invents its own. This page is the thing to sign off before any building starts. Everything below is rendered at its real size.

One open question

The hero lands at 36px, not the 40 you picked

Tailwind's standard ramp stops at 36. Adding a 40 would be exactly the bespoke step you ruled out, so the welcome screen comes down from ~42px today to 36px. If you want 40 back, say so and I'll add it as a documented one-off.

The ladder

Seven rungs, taken straight from Tailwind's default scale. Each size arrives welded to its line spacing, and every one of those spacings lands on the 4px grid Sero already uses for everything else. There is no 12px step: 14px is the floor.

The fourteen roles

A role is a complete recipe: face, size, spacing, weight, letter tracking, and where it matters a line length. A component picks a role and never picks a number. Note the last five: they are all 14px, and they tell themselves apart by weight and colour rather than by being a pixel apart.
